PHP-приложение для чтения сотрудников из CSV, фильтрации через GET и добавления через POST с серверной валидацией. См. разделы запуска и проверки ниже.

## Запуск
Требуется PHP 8.1+. Выполнить `php -S localhost:8000 -t public`, затем открыть http://localhost:8000.

## Структура
`public/` — точка входа; `src/` — логика; `templates/` — представление; `dataset/` — исходные CSV/JSON.
