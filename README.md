# Практическая работа №04 — обработка HTML-форм и CSV

**Студент:** Солопов Антон  
**Группа:** ЭПБО-01-25  
**Дисциплина:** Технологии разработки программного обеспечения

## Реализовано
- чтение предоставленного набора `dataset/employees.csv`;
- фильтрация сотрудников по отделу через GET;
- обработка формы добавления через POST;
- серверная проверка имени, email, отдела и стажа;
- сохранение введённых значений при ошибках;
- безопасное HTML-экранирование через `htmlspecialchars`;
- проверка сценариев из исходного `dataset/form_cases.json`;
- разделение репозитория, валидатора, контроллера и шаблона.

## Требования
PHP 8.1+ с расширением mbstring.

## Запуск
Из корня репозитория:
```bash
php -S localhost:8000 -t public
```
Откройте http://localhost:8000.

## Проверка
```bash
php -d zend.assertions=1 -d assert.exception=1 tests/validator_test.php
```
В интерфейсе проверьте фильтр по отделу, пустое имя, некорректный email, отрицательный и корректный стаж.

## Структура
- `public/index.php` — обработка HTTP-запроса;
- `src/EmployeeRepository.php` — чтение CSV;
- `src/EmployeeValidator.php` — валидация;
- `src/helpers.php` — безопасное экранирование;
- `templates/index.php` — HTML-представление;
- `dataset/` — исходные данные задания.

## Примечание
Новая запись отображается в результате текущего POST-запроса и не записывается обратно в CSV: исходный файл остаётся неизменным.
