## Результат
Приложение читает сотрудников из dataset/employees.csv, отображает таблицу, фильтрует её по отделу через GET и принимает нового сотрудника через POST. Серверная проверка контролирует ФИО, email, отдел и стаж. При ошибке значения сохраняются в форме. Пользовательский ввод экранируется через htmlspecialchars.

dataset/form_cases.json загружается приложением и проверяется тем же validateInput, который обрабатывает POST. BOM в заголовке CSV удаляется перед сопоставлением столбцов. Добавленная запись существует в списке текущего ответа; исходный CSV не перезаписывается.

## Запуск
PHP 8.1+. Дополнительные расширения и библиотеки не нужны.
php -S localhost:8000 -t public
Откройте http://localhost:8000.

## Тесты
php -d zend.assertions=1 -d assert.exception=1 tests/validator_test.php

## Структура
public/index.php — HTTP-обработка и HTML.
public/assets/styles.css — оформление.
src/functions.php — CSV, преобразование строки, валидация и экранирование.
dataset/ — исходные CSV и JSON.
tests/ — автоматические проверки.

GET передаёт параметры фильтра в URL и не изменяет данные. POST отправляет форму в теле HTTP-запроса. trim нормализует строки, htmlspecialchars предотвращает интерпретацию пользовательского ввода как HTML.
Путь данных: employees.csv → loadEmployees() → GET-фильтр → таблица; POST → validateInput() → ошибки либо строка текущего ответа.
